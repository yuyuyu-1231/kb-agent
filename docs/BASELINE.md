## 复现方法

```bash
python scripts/build_eval_set.py       # 生成评估集（含 chunk 交叉校验）
python scripts/eval.py                 # 跑 50 条，出 data/reports/{时间}.json/.md
python scripts/rescore.py <报告路径>     # 只改指标算法时离线重算，不重跑 Agent
python scripts/dump_chunks.py          # 导出 chunk 全文供人工核对
```

> 指标算法本身也迭代了三次（参见 `app/services/evaluation.py` 里的注释）：
> 关键词、引用、二者组合，三个版本的误拒率分别是 22.2% / 48.5% / 0%。
